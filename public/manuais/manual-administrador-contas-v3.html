Gestão de Contas de Acesso

Como dar acesso a uma pessoa nova, redefinir uma senha esquecida e remover o acesso de quem sai da equipe — desde a Fase 3 do login real (_local-adr-policy-202), o SIGCOI passa a exigir matrícula e senha de cada pessoa, e só o Administrador cadastra e gerencia contas.

1

O que mudou desde a Fase 3

Login real substitui o troca-de-perfil de um clique

Antes, qualquer pessoa cadastrada podia clicar no menu do cabeçalho e "virar" qualquer outra pessoa do sistema — inclusive o Administrador — sem senha nenhuma. Isso foi identificado como a falha mais grave de segurança do sistema numa auditoria dedicada, e foi corrigido de ponta a ponta:

  • Cada pessoa entra com matrícula + senha próprias.
  • Quem está agindo no sistema é sempre conferido pela sessão de login no servidor — nunca por um dado que a tela do navegador declara.
  • Não existe mais botão de "trocar de perfil". Sair de uma conta e entrar em outra agora é um login de verdade.
  • Só o Administrador logado cadastra pessoas novas, gera acesso e remove acesso.
O que isso significa na prática para você, Administrador Você passa a ser o único ponto de entrada de gente nova no sistema — e o único que pode tirar o acesso de alguém. Este manual é o passo a passo dessas duas tarefas.
2

Cadastrar uma pessoa nova

Configurações → Pessoas Cadastradas
1

Abra Configurações

No menu principal, vá em Ferramentas → Configurações (ou direto pelo atalho "Configurações", se sua tela for larga o suficiente para mostrá-lo).

Aba Configurações
2

Clique em "Cadastrar pessoa"

Esse botão só aparece para quem está logado como Administrador. Preencha nome completo, papel (Técnico, Curador, Administrador, Pesquisador ou Estudante), instituição e matrícula/registro profissional.

Painel "Pessoas Cadastradas"
3

Salve

A pessoa já aparece na lista — mas ainda não tem senha. Ela não consegue logar até você gerar o link de acesso (próximo passo).

Matrícula é o identificador de login O campo "matrícula / registro profissional" é o que a pessoa vai digitar para entrar no sistema — não pode repetir uma matrícula já cadastrada. Confirme com a pessoa qual matrícula ela quer usar antes de cadastrar.
3

Gerar o link de acesso

Um link de uso único para cada pessoa definir a própria senha
1

Localize a pessoa na lista

Em "Pessoas Cadastradas", encontre o nome de quem vai receber acesso (a pessoa que você acabou de cadastrar, ou alguém que já tinha conta e precisa de uma senha nova).

2

Clique em "Gerar link de acesso"

O sistema cria um link de uso único e mostra ele na tela, dentro de uma caixa azul, com um botão "Copiar" — e a data em que o link perde a validade.

Botão ao lado do nome da pessoa
3

Copie o link agora

Esse link só aparece uma vez. Se você fechar a tela ou atualizar a página sem copiar, precisa gerar outro (isso é seguro por padrão: o link nunca fica gravado em nenhum lugar legível, só um hash dele).

Validade O link vale por 72 horas, ou até ser usado uma vez — o que vier primeiro. Depois disso, gerar um novo link para a mesma pessoa é a solução (ver "Redefinir senha" abaixo).
4

Entregar o link e a pessoa entra pela primeira vez

Sempre por fora do sistema, num canal privado
1

Envie o link por um canal privado

WhatsApp, e-mail institucional ou entrega pessoal — nunca por um grupo público, mural ou qualquer canal que outras pessoas além da destinatária possam ver.

2

A pessoa abre o link e define a senha

Ela vê uma tela pedindo uma senha nova (mínimo 8 caracteres) e a confirmação dela. Ao salvar, recebe a confirmação "Senha definida com sucesso" e um botão para ir ao login.

3

A pessoa entra com matrícula + a senha que acabou de criar

A partir daqui, ela já está logada e vê o sistema normalmente, de acordo com o papel que você cadastrou para ela.

Nunca faça isto Não envie a senha em texto pelo mesmo canal que qualquer outra pessoa também acompanha, e não peça para alguém "usar o login de outra pessoa" — cada conta deve ser usada só por quem ela identifica. É exatamente essa garantia que a Fase 3 do login real existe para proteger.
5

Redefinir a senha de alguém

Esqueceu a senha, ou o link expirou antes de usar

A pessoa pode avisar sozinha, clicando em "Esqueci minha senha" na tela de login — mas isso não redefine nada por conta própria (não há e-mail nem SMS configurado no sistema): só registra um pedido que aparece para você em Configurações. Quem resolve continua sendo sempre o Administrador, com a mesma ação de "Cadastrar pessoa":

1

Veja se há um pedido pendente

Se alguém clicou em "Esqueci minha senha", um bloco amarelo "Pedidos de Redefinição de Senha" aparece no topo de Configurações, com o nome da pessoa e quando ela pediu. Sem pedido pendente, esse bloco não aparece — vá direto para "Pessoas Cadastradas".

2

Clique em "Gerar novo link" (no pedido) ou "Gerar link de acesso" (na lista de pessoas)

Os dois botões fazem a mesma coisa e funcionam mesmo que já exista senha definida antes. Quando a pessoa usar esse link, a senha antiga é substituída pela nova — não dá para ter as duas. Gerar o link também remove o pedido pendente da lista automaticamente.

3

Entregue o novo link do mesmo jeito (canal privado)

Assim que a pessoa definir a nova senha, a antiga deixa de funcionar imediatamente.

"Esqueci minha senha" nunca revela quem está cadastrado Mesmo que a matrícula digitada não exista no sistema, a pessoa vê a mesma mensagem de confirmação — por segurança, o sistema nunca diz se uma matrícula existe ou não. Só matrículas reais criam um pedido visível para você.
Se a pessoa ainda tem acesso, ela mesma pode trocar a senha Gerar link é só para quem perdeu o acesso de verdade. Se a pessoa ainda consegue logar (por exemplo, quer trocar a senha por precaução), ela mesma faz isso em menu do nome → Trocar minha senha — mais rápido, sem precisar do Administrador.
Limitação conhecida desta versão Nem gerar um link novo, nem a pessoa trocar a própria senha, invalida uma sessão já aberta em outro computador/navegador com a senha antiga — só troca a senha na próxima vez que alguém tentar logar com ela. Se o motivo for suspeita de acesso indevido, avise a pessoa para também encerrar sessões abertas (fechar o navegador onde estava logada) e, em caso de suspeita mais séria, considere remover e recriar a conta (próxima seção).
6

Remover o acesso de alguém

Quando a pessoa sai da equipe, ou o acesso precisa ser revogado
1

Vá em Configurações → Pessoas Cadastradas

Clique no ícone de lixeira ao lado do nome da pessoa.

2

Confirme a remoção

O sistema pede uma confirmação explícita antes de remover — não tem "desfazer" para esta ação específica (ela é sobre quem pode entrar, não sobre os dados do acervo).

O que continua preservado Remover uma pessoa não apaga nenhum registro que ela já assinou — recebimentos, custódias, laudos, reaberturas — nada disso desaparece. O nome dela permanece em todo o histórico e na Linha do Tempo de Auditoria exatamente como estava. Só o acesso futuro é cortado: a matrícula fica livre para ser reaproveitada, se um dia for o caso, e qualquer sessão dela ainda aberta para de funcionar na próxima ação que tentar fazer.
7

Segurança & boas práticas

O que o Administrador precisa lembrar sempre
  • Cada pessoa tem sua própria conta. Nunca crie uma conta "genérica" (ex.: "Laboratório", "Turno da Tarde") para várias pessoas usarem — isso quebra a rastreabilidade que todo o sistema existe para garantir.
  • Trate o link de definição de senha como se fosse uma senha temporária: envie só para a pessoa certa, por um canal privado, e nunca o publique em nenhum lugar (grupo, mural, planilha compartilhada).
  • O papel Administrador tem acesso à Zona de Risco (exclusão reversível de dados). Cadastre esse papel só para quem realmente precisa dele.
  • Esta versão (Alfa) ainda não tem autenticação em duas etapas nem exige troca periódica de senha — são pendências conhecidas, registradas em _local-adr-policy-202.

8

Perguntas frequentes

Dúvidas comuns do dia a dia

O sistema abriu direto numa tela pedindo para eu criar um Administrador. É normal?

Sim — isso só acontece quando o banco de dados está completamente vazio (nenhuma pessoa cadastrada), como na primeira instalação. É a única vez que o sistema aceita criar uma conta sem ninguém logado antes. Depois desse primeiro Administrador criado, essa tela nunca mais aparece.

Posso trocar a minha própria senha sem gerar um link para mim mesmo?

Sim. Clique no seu nome no canto superior direito → Trocar minha senha. Você precisa digitar a senha atual (por segurança, mesmo já estando logado) e a nova senha duas vezes. Vale para qualquer papel, não só Administrador.

Uma pessoa esqueceu a matrícula que cadastrou. O que faço?

Veja a lista em Configurações → Pessoas Cadastradas — a matrícula de cada pessoa aparece junto do nome dela.

Cadastrei a matrícula errada. Posso corrigir?

Nesta versão não há edição de pessoa já cadastrada. Remova a pessoa (o histórico dela é preservado, ver seção "Remover acesso") e cadastre de novo com a matrícula correta.

Quantos Administradores o sistema pode ter?

Quantos forem necessários — não há limite. Recomenda-se ter pelo menos dois, para que a gestão de contas nunca dependa de uma única pessoa disponível.
